# 🛒 Blinkit Grocery Sales Analysis Dashboard | Power BI

## 📌 Project Overview

The **Blinkit Grocery Sales Analysis Dashboard** is a data analytics project developed using Microsoft Power BI. The main objective of this project is to analyze grocery sales data and generate meaningful business insights through interactive visualizations and reports.

This dashboard helps understand sales performance, product categories, outlet characteristics, and customer ratings. It enables users to explore sales trends and identify patterns that can support data-driven business decisions.

## 🎯 Project Objectives

* Analyze overall grocery sales performance.
* Identify product categories contributing to sales.
* Compare sales across different outlet types and locations.
* Analyze the impact of outlet size and establishment year on sales.
* Understand the distribution of items based on fat content.
* Evaluate average sales and customer ratings.
* Present key business insights through an interactive dashboard.

## 🛠️ Technologies Used

* **Microsoft Power BI** – Dashboard development and data visualization.
* **Power Query** – Data transformation and preparation.
* **DAX (Data Analysis Expressions)** – Creating measures and calculating key performance indicators.
* **Data Analytics** – Exploring sales data and identifying business trends.

## 📊 Dataset Description

The project uses a Blinkit grocery dataset containing information about grocery products, sales, and outlet characteristics.

The dataset includes the following columns:

| Column Name               | Description                                 |
| ------------------------- | ------------------------------------------- |
| Item Identifier           | Unique identifier for each product          |
| Item Fat Content          | Fat content category of the product         |
| Item Type                 | Category of the grocery product             |
| Item Weight               | Weight of the product                       |
| Item Visibility           | Visibility of the product in the outlet     |
| Sales                     | Sales value associated with the product     |
| Rating                    | Customer rating associated with the product |
| Outlet Identifier         | Unique identifier for each outlet           |
| Outlet Establishment Year | Year in which the outlet was established    |
| Outlet Size               | Size category of the outlet                 |
| Outlet Location Type      | Classification of the outlet's location     |
| Outlet Type               | Type or category of the outlet              |

## 📈 Key Performance Indicators (KPIs)

The dashboard includes the following key performance indicators:

* **Total Sales:** Measures the total sales value across the dataset.
* **Average Sales:** Calculates the average sales value.
* **Average Rating:** Measures the average customer rating.

These KPIs provide a quick overview of overall sales performance and customer ratings.

## 📉 Dashboard Features

### 1. Sales Analysis by Item Type

Analyzes sales across different grocery product categories to understand category-level performance.

### 2. Outlet Establishment Analysis

Examines sales in relation to outlet establishment years to explore historical sales patterns.

### 3. Outlet Location Analysis

Compares sales across different outlet location types to understand location-based performance.

### 4. Outlet Size Analysis

Explores sales distribution across different outlet sizes.

### 5. Item Fat Content Analysis

Analyzes sales based on the fat content classification of grocery products.

### 6. Outlet Type Analysis

Compares sales across different outlet types to identify differences in outlet performance.

### 7. Customer Rating Analysis

Uses average customer ratings to provide an overview of customer feedback represented in the dataset.

## ⚙️ Project Workflow

1. **Data Collection:** Obtain the Blinkit grocery sales dataset.
2. **Data Preparation:** Inspect the dataset and prepare the data for analysis.
3. **Data Transformation:** Use Power Query to clean and transform the data where required.
4. **Data Modeling:** Organize the data for analysis in Power BI.
5. **DAX Measures:** Create measures for total sales, average sales, and average ratings.
6. **Data Visualization:** Build charts and KPI cards to present the analysis.
7. **Business Analysis:** Explore the visualizations to identify trends and patterns.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `Blinkit.pbit` file in Power BI Desktop.
4. If prompted, provide the required dataset or configure the data source.
5. Refresh the data if necessary.
6. Explore the dashboard and interact with the visualizations.

**Important:** A `.pbit` file is a Power BI template. It does not contain the imported dataset itself, so you may need to connect the original dataset before the report can display its results.
